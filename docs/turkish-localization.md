# Türkçe yerelleştirme

Pixbet arayüzünün varsayılan dili Türkçedir. Ana adres /tr/casino; eski Fransızca ve İngilizce yollar Türkçe karşılıklarına yönlendirilir. BigBang oyun açılışları sunucuda her zaman language: tr gönderir. Sağlayıcı Türkçe sunmadığında oyun içi arayüz İngilizceye dönebilir. Oyunların resmi adları ve sağlayıcı isimleri korunur. API alan adları ve hata kodları sözleşme uyumluluğu için çevrilmez.

Üç slider görseli bu proje için yapay zekâ ile özgün olarak üretilmiştir. Kaynak görseller public/sliders altında PNG olarak saklanır. Metin görselin içine işlenmez; erişilebilir HTML başlıkları olarak gösterilir.

Sanal kupondaki ₺ işareti yalnızca demo arayüzünün gösterim birimidir. BigBang oyun içi para birimini veya banka işlemlerini değiştirmez.
